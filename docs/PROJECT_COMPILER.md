# Project Compiler

The current compiler is a deterministic, offline rule engine. It identifies camera/CCTV and AI/LLM wording, matches only authorised computers, phones, and network hardware, assigns practical roles, and states missing capabilities. It does not buy equipment, deploy software, alter ownership, or rely on an LLM.

Future versions will parse explicit mandatory/preferred requirements against a graph of resources, produce topology edges, and retain build-plan approval history.
