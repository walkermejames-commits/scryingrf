# Baseline and change detection

The current implementation offers conservative evidence-based changes: a node first seen within 24 hours is described as a new observation, and an authorised resource without a recent update can be described as possibly offline. The UI does not call either event malicious, identify a physical device from an identifier, or present a cause as certain.

Next: named environments, scan-window rates, ordinary appearance/disappearance patterns, confidence, supporting observations, and alternative explanations.
